### คู่มือการใช้งาน Challenge – "Website Detective"

## 1. การติดตั้งและเข้าใช้งาน (Installation and Access)

# สิ่งที่ต้องเตรียม

- คอมพิวเตอร์หรือโทรศัพท์มือถือ
- เว็บเบราว์เซอร์ เช่น Google Chrome
- การเชื่อมต่ออินเทอร์เน็ต

# วิธีเข้าใช้งานผ่าน GitHub Pages

1. เปิด URL ของเว็บไซต์ GitHub Pages ของกลุ่ม
2. รอให้หน้าแรกของเว็บไซต์โหลดเสร็จ
3. คลิกเมนู **Challenge Page** บนแถบ Navigation Bar

# วิธีเข้าใช้งานผ่านไฟล์ในเครื่อง

1. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub Repository
2. เปิดโฟลเดอร์โปรเจกต์
3. เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์
4. คลิกเมนู **Challenge Page** บน Navigation Bar

## 3. วิธีทำ Challenge (How to Play)

# Challenge : Website Detective

**ประเภทกิจกรรม:** `discover`

**แนวคิดกิจกรรม**

ให้ผู้เล่นรับบทเป็นนักสืบเว็บไซต์ โดยตรวจสอบเว็บไซต์ที่เตรียมไว้ เพื่อค้นหาจุดที่ใช้งานยากหรือเข้าใจผิดได้ง่าย
พร้อมเสนอแนวทางแก้ไขโดยอ้างอิงหลัก Usability ที่เรียนในรายวิชา CS100

# ตัวอย่างจุดบกพร่องที่ต้องค้นหา

1. ตัวหนังสือเล็กหรือมีขนาดที่อ่านยาก
2. ปุ่มเขียนคำว่า "คลิกที่นี่" โดยไม่บอกว่าไปไหน
3. ช่องกรอกฟอร์มไม่มี Label
4. รูปภาพไม่มีคำอธิบาย (alt)
5. เมนูหรือปุ่มใช้งานบนมือถือได้ไม่สะดวก

# วิธีเล่น (ใช้เวลาประมาณ 5–7 นาที)

1. ผู้เล่นเปิดเว็บไซต์ทดลองบนมือถือหรือคอมพิวเตอร์
2. ค้นหาจุดที่ใช้งานยากอย่างน้อย 3 จุด จากทั้งหมด 5 จุด
3. เสนอวิธีแก้ไขสำหรับแต่ละจุดที่พบ
4. เจ้าของบูธตรวจสอบคำตอบโดยเปรียบเทียบกับใบเฉลย

# หลักฐานการทำกิจกรรม (Evidence)

ส่ง URL ของเว็บไซต์ทดลองที่ใช้ทำกิจกรรม

ควรใช้ URL ที่สามารถเข้าถึงได้อย่างต่อเนื่อง เช่น GitHub Pages และหลีกเลี่ยง URL ชั่วคราวหรือ IP Address ที่อาจเปลี่ยนแปลง

## 4. ข้อมูล Challenge ใน Portfolio (Portfolio Data)

ข้อมูลที่ใช้บันทึกทักษะและประเภทของกิจกรรมใน Portfolio มีดังนี้

json
{

],

}

สามารถเพิ่ม `"HTML/CSS"` ในรายการ `skills` ได้ตามความเหมาะสม

## 5. วิธีทดสอบระบบ (Testing)

ทำตามขั้นตอนต่อไปนี้เพื่อตรวจสอบการทำงานของเว็บไซต์

1. เปิด URL ของ GitHub Pages ผ่านคอมพิวเตอร์
2. เปิด URL เดียวกันผ่านโทรศัพท์มือถือ
3. ตรวจสอบว่าหน้าแรกของเว็บไซต์แสดงผลได้ถูกต้อง
4. คลิกเมนู **Challenge Page** จาก Navigation Bar
5. เปิด Developer Tools โดยกดปุ่ม F12
6. เลือกแท็บ **Network**
7. Refresh หน้าเว็บไซต์
8. ตรวจสอบว่าไม่มีการแจ้งข้อผิดพลาด 404 (Not Found) ของไฟล์ HTML, CSS และ JavaScript
